Chat App Writeup

The first three features I implemented were the ability to create a new chat, send messages, and add people to a group chat, as I found these to be the most pressing and important functionalities of any chat app.

Feature 1- Create a New Chat: Because my design displays all chats a user is in in a separate page from the individual chat itself, I decided my where for implementing this feature would be in a public channel that contains all chats the user is in. I decided to go with this slightly unconventional strategy for my chat app because I wanted to provide areas of my app clearly dedicated to either managing/entering groups or interacting within a group; I didn't think that not showing all chats simultaneously would be too confusing nor harmful to usability. For my what, I decided to include data such as the members of the chat and a reference to a title to include so that the user could enter a custom title on top of the information present in the JSON schema given in the website. For my who, I intended for my chat to only be visible to the user who created it and their members, which is why I add a "members" field to the schema.

Feature 2- Send/Delete Messages: For my what, other than what is already included in the sample JSON schema, I added information for the channel in which it is sent (the group chat) such that the message stays within that chat only. For my where, I implemented this in the individual chat page. For my who, anyone with access to the chat can send and view a message.

Feature 3- Adding People to a Group Chat: For my what, I decided on a JSON schema that included an object (person to add) as well as a target (the current group chat). For my where, I decided to implement it within the group chat channel, as adding members to a group chat happens within the context of a group chat. For my who, I decided everyone with access to the group chat can add members to it as well as see who is already a member.

Design Choices: I decided to stick closely with the prototype design I created for the previous homework; I therefore used screenshots of my prototype design in Cursor to help guide it in terms of creating a CSS file. My prompts were fairly verbose and specific in order to give it a good starting point for a design similar to the one I prototyped.
